# 功能介紹：
    這個程式主要是拿來做投資分析的，在做投資時我們會去考慮到他的內部報酬
    率，任何計畫都有一個投資金額、報酬、年數(預計幾年能返還)。因此我們利用
    了折現的概念，來去描述這項計畫的報酬率，也就是 IRR。IRR 公式為：
        Internal Rate of Return(IRR) = (Future Value/Present Value)^(1/Number of period) - 1
        內部報酬率 = (終值/現值)^(1/年數) - 1
    我們利用 IRR 去與台灣銀行定存利率做比對，假設 IRR>利率，則這個計畫值得
    投資，反之則是不值得投資，我就把一樣的錢丟去銀行，還不會有違約風險。
    我們導覽列總共有三個按鈕，一種是提供使用者輸入資料，第二種是告訴使用
    者計畫值不值得投資，第三種是觀看歷程記錄，而點擊歷程記錄的項目後會傳
    送內容為相關資訊的簡訊至特定號碼，因此開啟app後會要求傳送簡訊的權限。
